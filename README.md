# 💇‍♂️ Sistema de Reservas para Peluquería

[![PHP](https://img.shields.io/badge/PHP-8.2-purple?logo=php)](https://www.php.net/)
[![MySQL](https://img.shields.io/badge/MySQL-8.0-blue?logo=mysql)](https://www.mysql.com/)
[![Preact](https://img.shields.io/badge/Preact-673AB8?style=flat&logo=preact&logoColor=white)](https://preactjs.com/)
[![Docker](https://img.shields.io/badge/Docker-Compose-2496ed?logo=docker)](https://www.docker.com/)
[![License](https://img.shields.io/badge/License-ISC-green)](LICENSE)

Desarrollo de una aplicación web full-stack para la gestión de reservas en peluquerías, utilizando PHP, MySQL y frontend con Preact, desplegada mediante Docker.

El sistema permite la gestión de usuarios, especialistas y reservas, con flujos de autenticación y control de disponibilidad. Incluye integración de pagos y generación de reportes.

El proyecto está estructurado siguiendo un enfoque modular en el backend y una arquitectura organizada para facilitar su mantenimiento y evolución.

🚀 Live Demo: [🔗 reservas.jorgelizancandela.com](https://reservas.jorgelizancandela.com)
